# my-portfolio

My personal portfolio website, built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser. No build step needed.

## Customize

Search `index.html` for `TODO` to find the parts to fill in:

- Intro and About text
- Skills list
- Projects (title, description, tags, live/code links)
- LinkedIn link
- Profile photo: add `profile.jpg` to this folder and replace the `<div class="avatar">` with `<img src="profile.jpg" alt="Your name">`

Colors are defined at the top of `style.css` (`--accent` changes the main color).

## Deploy with GitHub Pages

1. Push to GitHub.
2. Go to **Settings → Pages**, set source to the `main` branch, root folder.
3. Your site will be live at `https://mukesharadhya.github.io/my-portfolio/`.
